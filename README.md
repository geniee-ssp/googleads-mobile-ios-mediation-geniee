# GoogleMobileAdsMediationGeniee

Geniee SDK adapter for Google AdMob/AdX mediation platform.

## Installation (Swift Package Manager)

Add this package to your Xcode project:

```
https://github.com/geniee-ssp/googleads-mobile-ios-mediation-geniee.git
```

## Requirements

- iOS 13.0+
- Xcode 16+
- [GNAdSDK](https://github.com/geniee-ssp/swift-package-manager-geniee-ios-sdk)
- [Google Mobile Ads SDK](https://github.com/googleads/swift-package-manager-google-mobile-ads)
